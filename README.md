# Portfolio React App

Modern personal portfolio built with React and Vite. All portfolio content is sourced from a JSON file so you can update projects, skills, experience, and contact details without touching component logic.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Content Updates

Edit `src/data/portfolio.json` to change the text shown in the site.
